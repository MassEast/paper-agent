Research Interest

This helps the AI find relevant papers on arXiv

How research interest generation works

If you already have text in the box, Generate refines and expands your existing description, using papers in My Collection as silent background context — the output will not mention specific papers or authors, only ideas, problems, methods, and goals.

If the box is empty, the LLM reads titles and abstracts of all papers in My Collection (up to 15, priority-ordered by tag) and synthesises a first-person research interest from scratch.

Tip: the more diverse and well-tagged your collection, the more precise the generated description.

What happens when you paste a URL

  1. arXiv URL — fetched directly from arXiv. Full enrichment: figure, citation count, page count, LLM summary & contributions, author institutions.
  2. Any other URL (PDF, ACL, NeurIPS, blog…)
    1. HTML page is fetched. If it has an arXiv link that matches the title → treated as arXiv paper (full enrichment above).
    2. If no arXiv link but a DOI is present (citation_doi meta tag) → Semantic Scholar is queried. If Scholar knows an arXiv preprint for that DOI → full arXiv enrichment.
    3. If no arXiv match → stored as a web paper. Title, authors, abstract (from citation_abstract only — not site taglines), and the stripped page body are extracted. LLM generates a summary from the full page text. No figure, no citation count.

All papers are tagged Important on add and skip LLM screening.

Search Keywords

How keywords work

An LLM reads your research interest + titles and abstracts of all papers in My Collection (up to 10, priority-ordered by tag), then outputs 3–6 short arXiv search phrases. The more papers you have tagged, the better the vocabulary.

Keywords are saved and reused by the nightly crawl automatically. Regenerate only when your research focus changes significantly.

Paper Crawler

How crawling works

  1. arXiv keyword search: Queries arXiv for each keyword phrase from the Keywords widget above; deduplicates results by ID. Results are returned newest-first, so the search stops as soon as papers fall before your start date — no unnecessary pagination. A global lock ensures only one arXiv session runs at a time (rate limit: 1 request / 3 s, single connection). If another crawl or search is active you'll see "Waiting for arXiv…" below.
  2. Semantic Scholar recommendations (if you have papers in My Collection papers): Fetches papers similar to your existing collection via the SemanticScholar recommendations API. Results are merged and deduplicated with the arXiv search results.
  3. Quick relevance filter: LLM receives your research interest + My Collection paper titles/abstracts + the candidate paper's title and abstract. Returns {"relevant": true/false}. 
    {{ prompt_relevance_quick }}
  4. Deep relevance check (papers that pass quick filter): same prompt but adds the full paper content (intro, methods, conclusion). 
    {{ prompt_relevance_deep }}
  5. Screening cache: Before calling the LLM, each crawl computes a short hash of your research interest + My Collection titles. Papers already screened with the same hash are skipped instantly — no LLM call needed. The hash changes (and screening reruns) only when you edit the research interest or tag/untag a paper in My Collection.
  6. Summary: For papers that pass both filters, LLM generates a 3-sentence summary, key findings, and main contributions.
  7. Institutions: A single batch call to the Semantic Scholar graph API fetches author affiliations for all newly added papers. Falls back to LLM extraction from page 1 of the PDF (which contains author/affiliation headers and footnotes) if Semantic Scholar returns nothing.
  8. Featured paper: LLM picks the single most relevant paper from all newly added ones — considering your research interest — to highlight in the crawl-complete email.
  9. Email: If any new papers were added, a crawl-complete notification is sent with stats and the featured paper. You can also manually notify for any paper using the bell icon.

How tagging improves future crawls

Papers in My Collection are used as reference context in the relevance check prompts. The more you curate, the more precisely the LLM understands your research scope. They also seed the Semantic Scholar recommendations — more tagged papers means better discovery of related work.
