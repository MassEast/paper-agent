# What's new

Changes people using the app will notice, newest first. `scripts/send_changelog.py` emails the latest entry
(or all entries since a date). Each entry ends with a link to the code changes on GitHub.

## 2026-11-27

- New Papers and Collection can be sorted by citations or by GitHub stars. Citation counts are refreshed every month, GitHub stars every week, starting tonight.
- Ask about this paper: the AI answers your question first, then points out anything in your notes that the paper doesn't support.

[Code changes](https://github.com/MassEast/paper-agent/compare/a2a227b...c3e7a2e)

## 2026-11-12

- New paper card: links to code and project page, emails of the corresponding authors, arXiv version, venue, Figure 1, and the papers of your Collection it cites.
- The share icon after a paper's title copies a link to its card.

[Code changes](https://github.com/MassEast/paper-agent/compare/6b17320...bdbb355)
