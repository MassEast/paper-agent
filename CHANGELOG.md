# What's new

Changes people using the app will notice, newest first. The latest entry is what `scripts/send_changelog.py` emails
around. Each entry ends with a link to the code changes on GitHub.

## 2026-11-27

- "My Collection" is now called "Collection": everyone in a project shares it.
- New Papers and Collection can be sorted by citations or by GitHub stars.
- Papers with code show their GitHub stars on the card, under Citations. They fill in over the next few nights.
- No code link found for a paper? Click the grayed-out Code button at the top of the card to add one.
- Citation counts are now kept up to date for New Papers too, not only for Collection (refreshed monthly).
- Ask about this paper: the AI answers your question first, then points out anything in your notes that the paper doesn't support.
- The abstract and main contributions now use the same font size as the AI summary.
